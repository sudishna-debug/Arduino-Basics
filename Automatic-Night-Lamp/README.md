Automatic Night Lamp 💡

📌 Description

An Arduino-based automatic night lamp that uses an LDR (Light Dependent Resistor) to detect surrounding light intensity and automatically control an LED.

🎯 Objective

To build a simple automatic lighting system that turns the LED ON in darkness and OFF in sufficient light.

🧰 Components

- Arduino Uno
- LDR
- LED
- Resistor
- Breadboard
- Jumper wires
- USB cable / power supply

⚙️ Working

The LDR senses the surrounding light intensity. Arduino reads the LDR value and compares it with a predefined threshold.

Bright environment → LED OFF
Dark environment → LED ON

Basic Flow

LDR → Arduino → LED

🔌 Circuit

The LDR is connected to an analog input of the Arduino, while the LED is connected to a digital output pin.
